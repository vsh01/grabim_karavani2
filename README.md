# Грабим Корованы 2

Трёхмерный экшен от первого лица про лесных эльфов, охрану дворца и злодея.
Открытый мир из четырёх зон, корованы, которые можно грабить, густой лес с
превращением дальних деревьев-картинок в настоящие трёхмерные деревья, и система
увечий, где отрубленную руку надо успеть перевязать.

**Играть: https://vsh01.github.io/grabim_karavani2/**

Игра работает в браузере. Ничего устанавливать не нужно, ни одного скачанного
ассета в проекте нет — весь мир, все модели и все текстуры строятся кодом при
запуске.

## Запуск

```bash
npm install
npm run dev        # открыть http://127.0.0.1:5173
```

Собрать статическую версию, которую можно положить куда угодно:

```bash
npm run build      # результат в dist/
npm run preview
```

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | идти |
| `Shift` | бежать |
| `Пробел` | прыжок |
| мышь | смотреть |
| `ЛКМ` | удар или выстрел |
| `R` | перевязать рану |
| `E` | обыскать труп, ограбить корован, торговать |
| `Tab` | мешок |
| `1`…`4` | сменить оружие |
| `Q` | приказ: напомнить, а злодею — взять новый |
| `F` `H` `G` | отряду: за мной, держать позицию, в атаку |
| `M` | карта мира и сохранения |
| `F5` / `F9` | быстро сохранить / загрузить |
| `Esc` | освободить курсор, закрыть окно |
| `F3` | служебная панель: кадры в секунду, зона, счётчики леса |

Управление читается по физическому коду клавиши, поэтому русская раскладка
работает так же, как английская.

## Мир

Карта — квадрат два на два километра, поделённый на четыре зоны с плавными
границами:

| Зона | Что там |
|---|---|
| Земли людей | равнины, деревня-рынок, отсюда выходят корованы |
| Земли императора | дворец на плато, казармы, патрули |
| Лес эльфов | очень густой лес, поляны, лагеря партизан |
| Горы злодея | скалы, перевал, старый форт |

Весь ландшафт строится из одного числа-сида: по нему воспроизводится тот же
рельеф, тот же лес и та же расстановка построек. Поэтому сохранению достаточно
запомнить сид, а не геометрию мира.

## Раны

Убить можно, а можно и не убить. Удар приходится ровно туда, куда наведён
прицел, и у каждой части тела свой запас прочности:

| Потеря | Что происходит |
|---|---|
| Рука | меньше урона, лук натянуть нечем, сильное кровотечение |
| Обе руки | драться нечем |
| Глаз | половина экрана уходит в темноту |
| Нога | ползком, пока не будет коляски или протеза |
| Голова, туловище | смерть |

Кровь — отдельная шкала. Отрубленная рука опустошает её примерно за полминуты:
не перевязался — умер. Лекарь затягивает раны и останавливает кровь даже на
культе, но отрастить отрубленное не может. Это умеет только протез: деревянная
нога, железная кисть, зачарованный глаз. Или коляска — по тракту она едет
бодро, по лесу и склонам почти никак.

Правила одни для всех. Стражнику можно отрубить руку ровно так же, как и вам, —
и он точно так же будет ползти и истекать кровью.

## Корованы

По трактам между городами ходят обозы: телега, погонщик и охрана. Ограбить
может кто угодно — сломить сопровождение и обыскать телегу.

Обозов в мире всего три, и ходят они по дорогам, а не по лесам: если долго не
попадаются, посмотрите карту по `M` — идущие корованы отмечены на ней точками.
Подойдя к обозу, вы увидите подсказку: пока телегу стерегут, там будет написано,
сколько человек её охраняет. Убивать всех до последнего не обязательно —
сопровождение перестаёт быть охраной, когда обращается в бегство или лишается
рук.

Последствия настоящие:

- хозяин груза запоминает обиду, и его люди начинают нападать при встрече;
- маршрут считается опасным, и на него ставят больше охраны;
- груз не доехал — в городе назначения на него подскакивает цена.

Из-за последнего награбленное выгоднее всего сбывать именно там, куда оно
шло, — но там же вас и будут искать.

## Три судьбы

При запуске выбирается сторона. Мир один и тот же, меняется только ваше место
в нём — и то, как с вами разговаривают.

**Лесные эльфы.** Начало на опушке, лук и нож в руках. В густом лесу вас
замечают вдвое позже, поэтому засада — ваш способ воевать. Приказы даёт старший
партизан в лагере: пощипать обоз императора, проредить патруль, проверить
горную тропу.

**Охрана дворца.** Начало у казарм, меч и кольчуга. Приказы даёт командир, и
без него новых не будет — на то она и служба: разогнать партизан, указать место
разбойникам, обойти дозором тракт. За выполнение платят и лучше относятся.

**Злодей.** Начало в старом форте, топор и мешок золота. Имя вы придумываете
сами. Командира у вас нет — приказ вы берёте у самого себя, где угодно и когда
захотите. Зато только вы можете нанимать людей: подошли, заплатили, и человек
пошёл за вами. Отряду командуют клавишами: за мной, держать позицию, в атаку.

Поверх этого стороны воюют между собой сами: стража ходит набегами на поляну
эльфов, банда спускается с гор к казармам, партизаны отвечают. Это происходит,
даже когда вы в другом конце карты.

## Сохранения

Мир целиком в файл не пишется. Ландшафт, лес, дороги и постройки
восстанавливаются из одного числа-сида, поэтому в снимок идёт только то, что
изменилось: где вы стоите, какие у вас раны и протезы, что в мешке, как к вам
относятся стороны, какой приказ на руках, где сейчас обозы и что почём.

Три слота лежат в браузере (`localStorage`), открываются на карте по `M`.
Быстрое сохранение — `F5`, загрузка — `F9`. У формата есть номер версии и
крючок миграции: обновление игры не должно ломать чужие сохранения.

## Звук

Звуковых файлов в проекте тоже нет. Удары, тетива, шаги и звон монет
синтезируются на месте через WebAudio: шумовой всплеск с быстрым спадом для
удара, скользящий по частоте тон для лука. Шаги привязаны к пройденному пути, а
не ко времени, поэтому совпадают с походкой и не тарахтят на месте.

## Как устроены деревья вдали

То самое требование из технического задания сделано так:

1. При запуске из шести пород деревьев строятся трёхмерные модели.
2. Каждая порода фотографируется с восьми сторон в общий атлас — прямо на
   видеокарте, за доли секунды.
3. Дальше лес рисуется тремя уровнями:
   - ближе 65 метров — полная модель со стволом, ветвями и кроной;
   - до 165 метров — упрощённая модель;
   - дальше — квадратик с фотографией, повёрнутый к камере и показывающий
     нужный из восьми ракурсов, поэтому дерево не выглядит плоским.
4. На границах уровней оба представления рисуются одновременно и рассыпаются
   встречными точками, дополняя друг друга до целого. Поэтому при подходе
   картинка превращается в объёмное дерево без щелчка.

Весь дальний лес — один вызов отрисовки на десятки тысяч деревьев.

```bash
npm run typecheck   # проверка типов

```

Прогон собранной игры в настоящем браузере — обходит все четыре зоны, снимает
скриншоты в `screenshots/` и падает, если в консоли есть ошибки:


## Публикация

Каждый пуш в ветку по умолчанию собирается и выкладывается на GitHub Pages
процессом `.github/workflows/pages.yml`: проверка типов, юнит-тесты, сборка,
публикация. Сломанное не выложится — проверки идут до сборки.

Один раз нужно разрешить публикацию в настройках репозитория:
**Settings → Pages → Build and deployment → Source: GitHub Actions.**
Процесс пытается сделать это сам, но токену `GITHUB_TOKEN` включение Pages
запрещено политикой, поэтому первый прогон без этой настройки останавливается на
шаге публикации. После настройки достаточно нажать «Re-run all jobs» — заново
собирать ничего не нужно.
